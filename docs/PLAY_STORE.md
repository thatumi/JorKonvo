## Build the release `.aab` with the real keystore
```bash
export JAVA_HOME=~/jdks/jdk-21.0.12.1+1 ANDROID_HOME=~/android-sdk
npm ci && npm run build            # matrix-core, then web
cd apps/web && npx cap sync android && cd android
cat > key.properties <<EOF          # gitignored — never commit
storeFile=/ABSOLUTE/PATH/upload-keystore.jks
storePassword=…
keyAlias=…
keyPassword=…
EOF
./gradlew bundleRelease             # → app/build/outputs/bundle/release/app-release.aab
rm key.properties
```
