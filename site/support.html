Before you report a bug

Mielőtt hibát jelentenél

  • Which platform (web browser / Windows / Linux / Android) and, for the web, which browser.
  • Melyik platform (webböngésző / Windows / Linux / Android), böngészőnél melyik böngésző.
  • What you expected to happen, and what happened instead.
  • Mit vártál, és mi történt helyette.
  • Whether it happens on a specific homeserver, or on every server you've tried.
  • Egy konkrét szerveren fordul elő, vagy mindegyiken, amit kipróbáltál.

Known limits right now

Jelenlegi ismert korlátok

  • QR sign-in is beta — many homeservers (including matrix.org) don't support the underlying protocol (MSC4108) yet, so it may show an error instead of a code. Password sign-in always works.
  • A QR-kódos bejelentkezés béta — sok szerver (köztük a matrix.org) még nem támogatja az ehhez szükséges protokollt (MSC4108), ezért hibát mutathat kód helyett. A jelszavas bejelentkezés mindig működik.
  • Group call media isn't end-to-end encrypted yet (1:1 calls are). See the privacy policy for the exact scope.
  • A csoportos hívások médiája még nem végpontok között titkosított (az 1:1 hívásoké igen). A pontos részleteket az adatvédelmi tájékoztató írja le.
  • iOS and Android app-store releases are still on the way — meanwhile, the web app works fully on mobile browsers.
  • Az iOS és Android áruházi kiadások még úton vannak — addig a webapp mobil böngészőben is teljes értékűen működik.

Verifying a download

Letöltés ellenőrzése

Linux and Windows release assets on Forgejo ship with a SHA256SUMS file and a detached SHA256SUMS.asc GPG signature, signed by the key below. Windows builds aren't yet signed with a code-signing certificate, so Windows will show a SmartScreen warning — this lets you verify the installer wasn't tampered with in the meantime.

A Linux és Windows release assetek a Forgejón egy SHA256SUMS fájllal és egy különálló SHA256SUMS.asc GPG-szignatúrával érkeznek, az alábbi kulccsal aláírva. A Windows-os build még nincs code-signing tanúsítvánnyal aláírva, így a Windows SmartScreen figyelmeztetést fog mutatni — ez viszont lehetővé teszi, hogy ellenőrizd, nem manipulálták-e a telepítőt közben.

gpg --import jorkonvo-release-signing-key.asc
gpg --verify SHA256SUMS.asc SHA256SUMS
sha256sum -c SHA256SUMS

Something to report about a specific homeserver?

Egy konkrét szerverrel kapcsolatos problémád van?

JorKonvo is a client for the Matrix network — most account and message-delivery issues are specific to the homeserver you're signed into, not the app. If you're using a server not operated by JorKonvo's developer, its operator is the right place to ask first.

A JorKonvo egy kliens a Matrix hálózathoz — a legtöbb fiókkal vagy üzenetkézbesítéssel kapcsolatos probléma az adott szerverhez köthető, nem az apphoz. Ha nem a JorKonvo fejlesztője által üzemeltetett szervert használsz, elsőként az adott szerver üzemeltetőjét érdemes megkeresni.
